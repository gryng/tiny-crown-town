# 設計の計算（3章〜魔王の城）

3章から先の魔物・主・親玉・魔王の数字を決めるために使った計算です。ゲーム本体（`index.html`）にはまだ入っていません。

- `calc.js` — 戦いの計算機。本体と同じ式（ダメージ＝攻撃−守り±1、会心、後列は狙われにくい、いやしの光、毒の沼の打ち消し）に、設計中の特徴（群れ・霊体・冷気・再生・鉄壁・手下を呼ぶ・2回攻撃）とジョブ（戦士・黒魔道士）を足したもの
- `design.js` — 魔物の数字、章ごとの目安の冒険者、章の決まり（`CHAPTERS`）、地図（`MAPS`）。`node design.js` で主・親玉との勝率の表が出る
- `report.js` — 仕様書に載せた表（別の答えの比較、魔王の城、道の魔物、レベルの見込み）。`node report.js`
- `check12.js` — 計算機が、いまの1章・2章と合っているかの確認

数字を変えたら `node design.js` と `node report.js` で、仕様書の「ねらい」の表から外れていないかを見ます。
実装するときは、`MAPS` と魔物の定義を本体の `NODES` / `EDGES` / `MON` / `AREAS` に写し、本体の自動プレイ（`autoCh1` と同じやり方）で章ごとの日数を確かめます。
