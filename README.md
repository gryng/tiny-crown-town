# Tiny Crown Town

小さな王様が城下町を建て、冒険者を毎朝送り出して帰りを待つ、2Dピクセルアートのブラウザゲーム。

王様は戦わない。冒険者は毎朝、家 → 公園 → 立て札 → 店 → 城門 と街を歩いて出発するので、建物の配置がそのまま出発時刻になる。洞窟の中は見えず、結果は翌朝の報告書で知る。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。
