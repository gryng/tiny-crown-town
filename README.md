# Tiny Crown Town

小さな王様が城下町を建て、冒険者を毎朝送り出して帰りを待つ、HD-2D風（ドット絵を3D空間に並べたジオラマ）のブラウザゲーム。

王様は戦わない。冒険者は毎朝、家 → 公園 → 立て札 → 店 → 城門 と街を歩いて出発するので、建物の配置がそのまま出発時刻になる。洞窟の中は見えず、結果は翌朝の報告書で知る。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。3D表示に three.js を CDN から読み込むので、ネット接続が必要です。

動作が重いときは画面下の「軽量表示」で、ぼかしや光のにじみを切れます。

## コードの構成

- `/*SIM-START*/` 〜 `/*SIM-END*/` — ゲームロジック（バランス調整済み。描画からは読むだけ）
- それ以降 — HD-2D描画（three.js / WebGL2）、HUD、報告書
